# Запуск собранной версии (практика № 6, вариант 2)

Из каталога `variant-2`:

```bash
go run ./cmd/app
```

В `cmd/app/main.go` создаются хранилище, адаптеры, сервис, обработчик и HTTP-маршруты.
Старый корневой `main.go` и все полученные файлы участников оставлены без изменений.
Новые `internal/repository/domain_adapter.go` и `internal/client/http.go` соединяют существующие интерфейсы с реализациями.

Маршруты: `POST /bookings`, `GET /bookings/{id}`, `PATCH /bookings/{id}/time`.

**Важно:** оригинальный репозиторий и сервис использовали разные типы и сигнатуры. Поэтому создан адаптер, а не переписаны исходные файлы. Поведение новых соединительных частей следует проверять отдельно; наличие тестов обработчика не покрывает сквозные сценарии.
